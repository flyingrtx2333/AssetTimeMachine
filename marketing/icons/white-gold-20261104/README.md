# White and gold app icon

The app icon now uses the same warm ivory and champagne-gold direction as the current PowerReps / 健身计数器 icon. The hourglass, clock orbit and ascending wealth line remain recognizable. The shared asset catalog supplies the iOS, Catalyst and native Mac targets.

Source: `asset-time-machine-white-gold-1024.png` (1024 × 1024, opaque PNG). All 13 existing AppIcon renditions were regenerated from this master; asset names and the catalog manifest are unchanged. The previous black-and-gold artwork remains recoverable from Git.

Generated using the built-in image generation tool with two references: the previous AssetTimeMachine icon (edit target) and the current GymCount iOS icon (palette/material reference). Standard macOS image resizing produced the required catalog dimensions.

Prompt:

> Restyle the existing AssetTimeMachine icon into the warm white and champagne-gold visual family of PowerReps. Preserve the central hourglass, thin circular clock orbit with sparse ticks, and ascending wealth line. No text, watermark, rounded tile corners or mockup.
