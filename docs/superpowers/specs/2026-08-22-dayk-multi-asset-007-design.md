# 日K多资产007：三角色趋势风险配置

状态：正式运行前冻结设计

协议：`ATM-SVP-2`

试验：`ATM-SVP2-DAYK-MA-007`

候选：`S-DAYK-MULTI-ASSET-007`

## 1. 目标与研究边界

001—006 主要把日 K 信号当作单笔交易触发器，无法持续管理整个跨资产组合。007 改为低复杂度目标仓位系统：黄金、美股和中国权益三个角色分别判断趋势，角色内部只保留一个更强资产，再通过逆波动与组合波动目标决定风险仓位，未使用部分持有人民币现金。

007 是已查看 `ATM-SVP2-HR-ARCH-001` 结果后的新试验。旧 HR-A 使用 20/60/120/252 日投票、全资产选前两名和更高频调仓，在 1% 成本下失败。007 不重跑或修改 HR-A，而冻结一个结构不同、直接对应用户低费率和三角色分散假设的独立候选。

趋势跟随在股票和商品上的跨市场依据可参考 Oxford *Review of Finance* 的 [Trend Following with Managed Futures](https://academic.oup.com/rof/article-abstract/21/4/1557/2338176)。该文献只支持经济假设，不构成本候选的业绩证据。

## 2. 日K信号和角色选择

全部判断使用 T−1 及更早的 CNY 计价日收盘序列；美股价格先沿用 App 的历史汇率转换。每20个共同交易会话重新评估一次。

资产只有在以下条件全部成立时合格：

1. T−1 收盘高于包含 T−1 的 `SMA(200)`；
2. 126会话总收益为正；
3. 63会话年化波动可计算且为正。

合格资产分为三个角色：

- 黄金：`gold_cny`；
- 美股：`nasdaq` 与 `sp500` 中只选一个；
- 中国权益：`csi300` 与 `shanghai_composite` 中只选一个。

角色内部评分固定为 `126会话收益 / max(63会话年化波动, 8%)`，选择最高者；完全相同时按内部 symbol 字典序确定，禁止结果后换规则。

## 3. 风险配置与执行

候选先按 `1 / max(63会话波动, 8%)` 生成角色间相对权重。若至少两个角色有效，任何单资产相对权重不超过50%，超出部分按其余资产原始逆波动权重分配。

随后用所选资产最近63个会话的实际组合收益估计年化波动，并令：

`目标总仓位 = min(100%, 10% / 预测组合波动)`

若只有一个角色有效，即使波动目标允许更高仓位，该资产仍最多50%；若没有角色有效则100%现金。最终不做空、不融资、总风险仓位不超过100%、现金不得为负。

目标每20个共同会话更新，执行层使用10% hard rebalance band。严格按 T−1 计算目标，在下一共同交易会话收盘执行。不使用止损、止盈、固定持有期或日内高低价。

## 4. 数据、成本与对照

- 资产：黄金、纳指、标普500、沪深300、上证综指及人民币现金；
- 共同评估窗口：`2012-07-05 — 2026-08-20`，与冻结 V11 的七折窗口一致；
- 候选本身不读取 NFCI；NFCI initial-release 数据只用于运行完全相同窗口的 V11 控制；
- 每次成交手续费 `0.005%`，主结果滑点为零；压力测试每次成交额外 `0.05%` 不利滑点；
- 现金使用现有 `CashYieldCNY`；
- `V11-CONTROL` 使用同一市场输入、同一窗口和同一0.005%/零滑点最终执行成本；V11内部冻结决策影子成本保持不变；
- `C-DKMA007-EQUAL-ELIGIBLE` 使用完全相同的趋势过滤和角色选择，但有效角色等权、不做10%波动缩放；单角色同样只持50%，用于检验逆波动与波动目标是否增加风险调整价值。

非收益冒烟覆盖3696个评估会话、154次目标变化；最大总仓位100%、最大单资产50%、最低现金0，美股/中国角色冲突均为零。

## 5. 正式PASS门槛

PASS 必须全部成立：

- 候选在同成本共同窗口的 CAGR >= V11，Sharpe >= V11，MDD <= V11；
- 候选 Sharpe 高于等权趋势对照；
- 候选 CAGR 至少高于现金5个百分点、Sharpe >=1.0、MDD <=15%；
- 七个固定时间折至少六个 Sharpe >0，至少四个 Sharpe >1；
- 2020+ 和2022+ CAGR 均高于全窗口现金 CAGR；
- 0.05%不利滑点下 CAGR 至少高于现金3个百分点且 Sharpe >0.75；
- 目标变化数20—200，实际成交数不超过500；
- 最大总仓位 <=100%、最小目标权重和现金非负、单资产 <=50%、区域角色冲突为零。

## 6. 冻结边界

正式结果打开后不得修改200/126/63周期、20会话频率、10%执行带、10%波动目标、8%波动地板、50%单资产上限、角色映射或评分公式。不得测试63/252日动量、SMA100、周频/季频、top-2全资产、相关性聚类、止损、NFCI叠加、动态角色权重或只删除弱地区。任何变化必须成为新的预注册试验。

007 仍是结果知情的回顾性研究；即使通过，也不能替代 V11 尚在运行的真正前瞻账本。
