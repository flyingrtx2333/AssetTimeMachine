# 日K高速005：多因子压力反转

状态：正式运行前冻结设计

协议：`ATM-SVP-2`

试验：`ATM-SVP2-DAYK-HS-005`

候选：`S-DAYK-HIGH-SPEED-005`

## 1. 目标与规则

004 表明两日急跌回补在三个资产上均有正收益，但组合 Sharpe 和滑点压力 Sharpe 未过门槛。005 不调整 004 的 SMA、急跌、止盈或持有期参数，而是检验“多个正交日 K 因子共同确认，能否过滤低质量回补”。

基础条件保持不变：

1. T−1 收盘高于 `SMA(200)`；
2. T−3 收盘到 T−1 收盘的两日跌幅至少为 `1.00 × ATR(14)`；
3. 全部指标只使用 T−1 及更早的真实日 K。

基础条件满足后，由四个因子等权投票：

- 趋势排列：`SMA(50) > SMA(200)`；
- 短期超卖：三日简单 RSI `RSI(3) <= 30`；
- 波动扩张：`ATR(14) > ATR(60)`；
- 买盘拒绝：T−1 `close > open`，且收盘位置 `(close-low)/(high-low) >= 0.60`。

至少获得 2/4 票才在 T 日开盘买入。退出规则与 004 完全一致：入场日不退出；从第二个资产交易日起触及 `entry open + 0.75 × ATR(14)` 止盈，否则第五个资产交易日收盘退出。同一资产不叠加仓位，不做空、不融资、不使用杠杆。

## 2. 数据、成本和资金

- 黄金 `gold_cny`、纳斯达克 `nasdaq`、标普 500 `sp500`；
- 仅使用真实 OHLC，统一窗口 `2017-04-11 — 2026-08-20`；
- 单资产最多 100%；组合每资产固定 1/3 袖套；未使用资金按 `CashYieldCNY` 计息；
- 每次成交手续费 `0.005%`；主结果滑点为零；压力测试每次成交额外 `0.05%` 不利滑点；
- 跨市场休市日对已持有资产沿用上一有效收盘价估值，不推进其持有期、不触发止盈。

非收益检查得到黄金 78、纳指 133、标普 122 次完整往返，组合 333 次；每笔持有 2—5 个资产交易日，最终持仓为零。因此保留每资产至少 75 笔的正式样本门槛。

## 3. 对照和正式门槛

`C-BASE-PULLBACK-*` 是 004 的基础规则：保留 SMA200、两日 1 ATR 急跌、相同退出、资金和成本，但不要求四因子票数。它直接检验多因子过滤是否提高 Sharpe。现金对照使用相同窗口。

PASS 必须全部成立：

- 至少两个单资产 CAGR 高于现金，至少两个单资产 Sharpe > 0；
- 每个单资产至少 75 次完整往返；
- 组合 CAGR 至少高于现金 2 个百分点，Sharpe >= 1.0，最大回撤 <= 12%；
- 组合 Sharpe 高于 `C-BASE-PULLBACK-COMBINED`；
- 组合平均每笔净收益 > 0，profit factor >= 1.10；
- 五个固定时间折至少四个 Sharpe > 0；
- 2020+ 和 2022+ CAGR 均高于全窗口现金 CAGR；
- 压力测试 CAGR 高于现金且 Sharpe > 0.5；
- 最大总持仓 <= 100%，日终现金非负，每笔持有 2—5 个资产交易日，最终持仓为零。

## 4. 冻结边界

本试验只有一个候选，不测试 1/4、3/4 或 4/4 票，不改变四个因子的周期或阈值，不给因子优化权重，也不修改 004 的退出规则。正式结果打开后不得删除表现弱的因子或资产。任何不同票数、加权打分、止损、成交量、MACD 或动态仓位都属于新试验。

005 是结果知情的回顾性试验，不是独立留出样本。指数 OHLC 仍是研究代理；即使通过，也必须映射到可交易工具重新验证。
