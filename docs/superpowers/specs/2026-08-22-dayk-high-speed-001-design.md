# 日K高速001：趋势内跳空回补日内策略

状态：正式运行前冻结设计

协议：`ATM-SVP-2`

试验：`ATM-SVP2-DAYK-HS-001`

候选：`S-DAYK-HIGH-SPEED-001`

## 1. 机制

本策略检验一个独立于 V11 的短周期机制：当资产仍处于中期上升趋势，但下一交易日开盘出现相对于近期真实波幅的向下跳空时，隔夜抛压可能在同一交易日部分回补。

规则只读取开盘时已经知道的信息：

1. 使用 T−1 及更早的 50 个收盘价计算 `SMA(50)`；
2. 使用截至 T−1 的 14 个完整日 K 计算 `ATR(14)`；
3. T 日开盘时，若 T−1 收盘价高于 `SMA(50)`，且 `T−1 close − T open >= 0.25 × ATR(14)`，则产生买入信号；
4. 以 T 日开盘价买入；
5. 止盈价固定为 `T open + 0.25 × ATR(14)`；当日最高价达到止盈价时按止盈价卖出，否则按 T 日收盘价卖出；
6. 不设止损，不隔夜，不做空，不融资，不使用杠杆。

T 日最高价和收盘价只用于判定事先冻结的退出方式，不参与 T 日开盘买入信号或止盈目标计算。由于没有日内止损，同一天内高低点先后顺序不存在止盈/止损歧义。

## 2. 资产与资金

- 黄金：`gold_cny`；
- 纳斯达克：App 角色 `nasdaq`，底层数据 `nasdaq_composite`；
- 标普 500：`sp500`；
- 单资产验证：有信号时最多使用 100% 资金；
- 三资产组合：每个资产固定 1/3 独立袖套，有信号的袖套才交易，未使用资金保留为人民币活期现金；
- 每日收盘后持仓必须为零。

统一评价窗口为 `2001-09-05 — 2026-08-20`。开始日由三条序列中最晚满足 50 根前置信号 K 线的日期机械确定；结束日取三资产共同最新交易日。

## 3. 成本

- 用户指定手续费：每次成交 `0.005%`（万分之 0.5）；
- 一次完整买卖收取两次，合计名义手续费 `0.01%`；
- 主结果不额外加入滑点；
- 预注册执行压力：每次成交额外加入 `0.05%` 不利滑点，规则和信号不得改变。

主结果与压力结果必须同时报告，不能只保留较好者。

## 4. 对照

- `C-GAP-*`：保留同一跳空阈值、ATR 止盈、当日平仓和成本，只移除 `close > SMA(50)` 趋势门槛；用于判断趋势过滤是否真的增加信息；
- `C-CASH-COMBINED`：相同评价期内全部持有现有人民币活期现金模型；
- 买入持有曲线由共享 App 引擎作为描述性基准输出，不作为唯一通过标准。

## 5. 正式门槛

正式 PASS 要求所有条件同时满足：

- 三个单资产中至少两个 CAGR 高于现金对照；
- 三个单资产中至少两个 Sharpe > 0；
- 每个资产至少 150 次完整日内往返；
- 三资产组合 CAGR 至少高于现金对照 2 个百分点；
- 三资产组合 Sharpe >= 1.0；
- 三资产组合最大回撤 <= 10%；
- 三资产组合 Sharpe 高于去除趋势门槛的匹配跳空对照；
- 三资产组合平均每笔净收益 > 0、profit factor >= 1.05；
- 七个固定时间折中至少五个 Sharpe > 0；
- 2020+ 与 2022+ CAGR 均高于全期现金对照 CAGR；
- 每次成交加入 0.05% 不利滑点后，组合 CAGR 仍高于现金、Sharpe > 0.5；
- 最大日内总资金占用 <=100%、日终现金不为负、隔夜持仓天数为零。

## 6. 失败和后续

本试验只有一个候选，不搜索 SMA、ATR、跳空倍数、止盈倍数、资产专属参数或止损。正式结果一旦打开，不得为了得到更好结果在本试验内修改规则。任何不同阈值、RSI/量价附加因子、隔夜持有、止损、动态仓位或实际 ETF 映射都必须作为新 lineage 重新预注册，并继续计入多重试验账本。

指数 OHLC 是研究代理，不代表可直接按指数点位成交；即使本试验 PASS，也必须在可交易工具、时区、开盘集合竞价、滑点和容量上完成新的执行验证后，才能考虑进入产品。
