# 日K高速002：趋势内波动压缩后的日内向上释放

状态：正式运行前冻结设计

协议：`ATM-SVP-2`

试验：`ATM-SVP2-DAYK-HS-002`

候选：`S-DAYK-HIGH-SPEED-002`

## 1. 机制

本策略不调整 001 的跳空阈值，而是检验不同机制：上涨趋势中的窄幅整理若收在当日高位，可能代表卖压有限、信息尚未完全反映，并在下一交易日出现日内向上释放。

规则只读取 T 日开盘时已知的信息：

1. 用截至 T−1 的 50 个收盘价计算 `SMA(50)`；
2. 用 T−2 及更早的 14 个完整日 K 计算基准 `ATR(14)`；
3. T−1 的真实波幅必须不高于 `0.75 × ATR(14)`；
4. T−1 收盘位置 `(close − low) / (high − low)` 必须至少为 `0.75`；
5. T−1 收盘价必须高于 `SMA(50)`；
6. 条件满足时在 T 日开盘买入；目标固定为 `T open + 0.25 × ATR(14)`；T 日最高价触及目标则按目标卖出，否则按 T 日收盘卖出；
7. 不设止损、不隔夜、不做空、不融资、不使用杠杆。

ATR 特意截止到 T−2，避免被用来定义“压缩”的 T−1 K 线同时进入自身比较基准。T 日最高价和收盘价只决定冻结后的退出，不参与开盘信号。

## 2. 资产、资金与成本

- 黄金 `gold_cny`、纳斯达克 `nasdaq`、标普 500 `sp500`；
- 单资产有信号时最多使用 100% 资金；三资产组合各固定 1/3 袖套；
- 未交易资金按现有 `CashYieldCNY` 模型计息；每日收盘后持仓必须为零；
- 统一评价窗口：`2001-09-05 — 2026-08-20`；
- 每次成交手续费 `0.005%`，主结果滑点为零；
- 固定压力测试：每次成交额外加入 `0.05%` 不利滑点。

## 3. 对照与正式门槛

`C-COMPRESSION-*` 保留压缩、收盘位置、ATR 止盈、当日退出、成本和资金规则，只移除 `close > SMA(50)` 趋势门槛。现金对照为相同窗口的 `C-CASH-COMBINED`。

正式 PASS 要求全部成立：至少两个资产 CAGR 高于现金且 Sharpe > 0；每个资产至少 150 次往返；组合 CAGR 至少高于现金 2 个百分点、Sharpe >= 1、MDD <= 10%；组合 Sharpe 高于匹配压缩对照；平均每笔净收益 > 0 且 profit factor >= 1.05；七个固定时间折至少五个 Sharpe > 0；2020+ 与 2022+ CAGR 均高于全期现金 CAGR；压力测试 CAGR 高于现金且 Sharpe > 0.5；日内总资金占用不超过 100%、日终现金非负、隔夜持仓为零。

## 4. 冻结与解释边界

本试验只有一个候选，不搜索 SMA、ATR、压缩倍数、收盘位置、止盈倍数或资产专属参数。正式结果一旦打开，不得在 002 内修改规则或删除弱资产。任何止损、量价因子、RSI、动态仓位、隔夜持有或不同阈值都属于新的预注册试验。

001 的结果已经暴露，因此 002 仍是回顾性证据，不是独立留出样本。指数 OHLC 只是研究代理；即使通过，也不能解释成可以按指数点位直接成交，必须另做可交易工具和真实执行验证。
