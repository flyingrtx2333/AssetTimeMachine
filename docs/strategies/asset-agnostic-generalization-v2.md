# 资产无关低噪配置 v2：冻结泛化验证协议

> 状态：研究候选，尚未加入 App 精选策略目录
> 引擎：`AssetAgnosticBacktestEngine`
> 参数：`AssetAgnosticStrategyConfig.frozenV2`
> 冻结原则：以下参数与最终盲测门槛在下载最终 holdout 数据之前固定，最终 holdout 结果不得用于继续调参。

## 1. 目标

把现有策略中依赖 `nasdaq/sp500/csi300/shanghai/gold` 等具体资产角色的逻辑，改造成只依赖价格路径统计量的资产无关配置器。策略不得根据 ticker、国家、地区或资产名称分支。

## 2. 冻结 v2 参数

- T−1 生成目标，T 日收盘执行；
- 单边交易费：1.00%；
- 单边滑点：0.05%；
- 不允许融资，不允许负现金，不允许做空；
- 预热：252 个共同交易会话；
- 目标复核：每 42 个共同交易会话；
- 动量窗口：63 / 126 / 252；
- 趋势均线：MA200；
- 波动/协方差窗口：63；
- 目标年化波动：14%；
- 最多持有 8 个合格资产；
- 单资产上限：40%（当资产数过少时自动放宽到可行下限）；
- 执行偏离带：20%；
- 目标变化低于 18% 时抑制非必要调仓；
- 入场使用严格趋势确认，已有仓位使用小幅迟滞区，降低高交易费环境下的均线反复穿越成本；
- 合格资产按动量/下行波动/趋势效率打分，并用波动与正相关惩罚进行风险分配；
- 根据趋势宽度、组合回撤和预测组合波动缩放总风险；
- 任何规则都不得读取资产名称或市场类别。

## 3. 开发诊断集（不算最终 OOS）

第一轮曾使用以下未进入原低噪增强生产篮子的序列做开发诊断，因此它们不再具有最终盲测资格：

- Dow Jones；
- Hang Seng；
- Nikkei 225；
- Shenzhen Component；
- ChiNext；
- WTI CNY proxy。

v1 在该诊断集暴露出两个问题：资产名顺序依赖和风险预算过低。v2 只根据这些诊断问题做结构性修正；最终结论不得再依赖这批数据。

## 4. 最终资产 OOS holdout

最终验证计划使用此前未参与原策略研发、也未参与 v1/v2 诊断的独立国家股票市场。原计划直接下载 KOSPI、DAX、FTSE 100 等本地基准；由于当前验证机到 Yahoo/FRED 普通 TLS 下载链路被网络层阻断，在**不查看策略回测结果、不改变 v2 参数或 PASS 门槛**的前提下，数据代理统一改为 FRED 发布、Nasdaq 提供的国家股票指数日线：

- NASDAQ Korea Index（韩国，`NASDAQNQKR`）；
- NASDAQ Germany Index（德国，`NASDAQNQDE`）；
- NASDAQ UK Index（英国，`NASDAQNQGB`）；
- NASDAQ France Index（法国，`NASDAQNQFR`）；
- NASDAQ Australia Index（澳大利亚，`NASDAQNQAU`）；
- NASDAQ India Index（印度，`NASDAQNQIN`）；
- NASDAQ Brazil Index（巴西，`NASDAQNQBR`）；
- NASDAQ Canada Index（加拿大，`NASDAQNQCA`）。

该替换只改变 holdout 的市场代理与下载通道，仍然是八个此前未用于策略开发的国家权益市场；所有系列使用同一提供方、同一指数口径，避免混用不同供应商的复权和交易日规则。如果某一系列无法返回足够历史，允许缺失，但最终至少需要 6 个 holdout 资产才能判定通过。

## 5. 最终 PASS 门槛（下载 holdout 前冻结）

必须同时满足：

1. 至少 6 个最终 holdout 资产具有 >= 252+ 个可用会话；
2. 单资产独立运行时，Sharpe > 0 的比例至少 62.5%；
3. 单资产 Sharpe 中位数至少 0.20；
4. 所有可用 holdout 组成的资产无关篮子年化收益 > 0；
5. holdout 篮子 Sharpe >= 0.45；
6. holdout 篮子最大回撤 <= 25%；
7. holdout 篮子最大回撤不得高于同资产等权买入持有基准；
8. ticker 全部重命名后，CAGR / MDD / 波动 / Sharpe / 交易次数在数值容差内保持一致；
9. 最终验证仍必须计入 1% 单边交易费与 0.05% 单边滑点。

不要求策略 Sharpe 必须高于买入持有 Sharpe，因为该候选的目标是可迁移的风险控制与配置，而不是在所有牛市样本中强制战胜长期满仓；但回撤必须优于或等于对应买入持有篮子。

## 6. 数据口径限制

最终跨国指数验证默认使用各指数本币价格路径，主要检验策略规则对市场结构的泛化，而不是人民币投资者的可实现收益。若未来产品化，应额外增加历史 FX、ETF/基金跟踪误差、交易时区和税费模型，并再次执行同一冻结验证协议。
