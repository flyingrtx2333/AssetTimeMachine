# KE25 回测与每日调仓

用户要求同时实现实时规则和每日调仓，最终策略 ID 为 `ke25`，规则版本为 `ke25-forward-v1-2026-10-21`。App 策略大全、量化页面每日调仓和提醒选择器均通过现有统一注册表获得这一条研究策略；不修改默认/推荐项和既有策略。历史中的 KE25 仍是事前对照 `ke-b25-mix-control`，用户选择使用不改变研究角色，不等于已稳健达到夏普1.3。

## 固定机制

以原五资产价格生成 P：75% CDF252参与政策加25%连续三跌政策。K以原P为父，独立计算原币种区间/收盘冲突H1、313观察期重置的EMA13和MACD12/26/9限增、三期向下全区间缺口暂停，再按各现存股票腿取并行MIN；限增组件的记忆只写回自身，不写回K或实际持仓。E用原币种前20bar最高价严格突破入场，以入场bar最低价为冻结退出边界，UNKNOWN按原合同清状态；四股各1/6，黄金为P黄金坐标的1/3。最终按完整键并集合成 `.75*K + .25*E`，保留零键，不重配闲置现金、不做空、不融资、总敞口不超过100%。

四个原成功信号模块原字节复制，parent金融表达式沿用原CDF/negative-streak原生Swift。P/K/E都从当前传入真实价格、观察掩码与原生OHLC重新生成，生产实现不读取旧目标表。历史frame、targets及rawhistory仅在tools/fixtures用于工程对照，不打包进App。

## 明确的实时延伸合同

共同观察时钟以2002-01-04完整历史为锚。CDF252继续原252观察期重置与剩余期限；负连续段原63起每5观察期发布。为了原历史末期逐日位级一致，保留原5753观察期的最终块到期及该期无新发布；其后5758、5763等原5期时钟继续正常更新，不再使用旧5749上界。其余K/E状态在新价格到来时按同一规则延续，不在研究截止日重置或无限沿用固定目标。这个前向延伸是本次明确的新版本，未经未来独立验证，不能借原夏普1.2605声称前瞻达标。

每日建议直接取最新已完成真实共同观察期的desired目标，记录实际asOf，不把模拟账户尚未结算的accepted目标冒充最新建议，也不制造一个假报价日来计算指标。回测按严格前一源收盘成交，保留原每日pending卖重检、既有settledcash可买、当日卖款递延及cash收益。默认本金100000、fee每fill0.025%、slippage0、band4%；用户费用和滑点影响成交，不影响信号。缺少完整锚定历史或不合法数据不输出建议。
