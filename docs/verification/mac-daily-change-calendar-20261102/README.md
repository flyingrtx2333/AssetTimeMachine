# 时光机每日净资产变动日历

曲线下方增加 GitHub 贡献图式年度日历。一格一天，红／绿表示净资产增加或减少，颜色深浅表示差额大小。悬停显示日期、带正负号的人民币差额及实际比较日期；点击有记录的格子选中对应快照并联动原有明细，超出曲线当前范围时切换到全部历史。

口径：同一天多条快照取按记录时间、更新时间排序的最后一条收盘观察，不相加；净资产为总资产减负债。跨年保留前一年最后一条记录作为基准。无记录日期留空、首条无基准不虚构涨幅、零变动为中性色，未来记录不展示。跨缺失日期的差额注明实际比较日期；显示金额按人民币分取整，不修改原始数据。它表示记录的净资产变化，包含现金流和录入调整，不是投资收益计算。

配色入口位于日历右上角调色板及“设置 → 外观 → 涨跌配色”。默认跟随系统地区：`CN` 红涨绿跌，其他地区绿涨红跌；可手动选任一预设。两个入口共享本机持久偏好；预览使用隔离偏好，不改变用户设置。原有业务数据、同步和策略不变。
