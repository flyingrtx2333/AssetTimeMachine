# Mac 时光机 · 等值黄金

时光机曲线增加“等值黄金”图例，默认隐藏。点击启用，再次点击隐藏；启用时显示所选／悬停日期的黄金克数。计算与手机端一致：当天总资产 ÷ 当天记录的人民币金价（元／克），不是净资产或实际持有黄金数量。

黄金使用独立的右侧克数标尺和绿色虚线，人民币金额在左侧。缺失、非正或非有限金价不参与换算，并将曲线断开；不使用其他日期的价格补值。长历史按黄金序列自身的高低点采样，避免只按资产金额采样时丢失金价变化。首页曲线保持原有行为。

验证：

- 独立原生 Mac Release 构建通过。
- `scripts/test_native_gold_equivalent.py` 编译实际绘图计算源码，检查总资产口径、零值、无效报价、断点、有限坐标，以及资产金额不变时一万条记录中黄金换算极值的保留。
- [原生点击检查](native-toggle-check.json)：实际图例和图表源码，真实 AppKit 鼠标事件，启用／隐藏／再启用为 `[true, false, true]`。
- [隐藏](gold-hidden-light.png)、[浅色启用](gold-visible-light.png)、[深色启用](gold-visible-dark.png)：752×334 点原生组件、两倍像素；全部使用虚构数据，包含两天缺失金价。它们是图表组件检查，不是个人账户截图。
- 三语言本地化审计通过。iPhone Release 编译兼容检查通过，使用仓库维护的构建脚本；本次没有运行无关策略或同步回归。
