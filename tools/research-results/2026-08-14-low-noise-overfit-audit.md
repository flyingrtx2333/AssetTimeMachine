# 低噪增强与 NFCI C3/L3 过拟合审计

日期：2026-08-14

状态：**审计进行中；已发现并修复一项决策/执行成本耦合缺陷。低噪增强继续作为现有 App 策略，但其历史最优指标需要降置信度解释；NFCI C3/L3 尚未进入 App。**

## 1. 核心结论

本轮审计发现两类性质完全不同的问题：

1. **工程缺陷：手续费/滑点曾泄漏到低噪增强的决策层。** 用户修改交易成本时，内部稳健/进攻/恢复影子引擎净值随之改变，导致路由状态和未来目标仓位改变。于是“降低手续费”实际上变成了“换策略”。该问题已经修复：低噪增强内部决策影子引擎永久冻结为研究口径 `1.00% fee + 0.05% slippage`；用户设置只影响最终真实成交模拟。
2. **研究选择风险：低噪增强最后一层有两组明显的参数甜点。** `24.4%` 执行偏离带与 `1.22 / 1.24 / 1.30` 主动收益缩放簇在 ±10%~20% 扰动下明显退化。说明低噪层存在实质参数拟合风险，不能把历史 Sharpe 1.509 当作同等可信的未来真值。

同时也得到两项正面证据：

- 低噪增强的长期正收益并非完全由最后几组参数制造：3/5/10 年滚动窗口 Sharpe 全部为正，主要 Sharpe 跃升来自更早的 Cash Confidence 风险控制层；
- **NFCI C3/L3 外部因子模块本身比低噪最后一层稳健得多。** 它通过费用不变性、阈值平台、事件 jackknife、延后启用、底座参数扰动、配对主动收益 HAC/bootstrap，以及 27 组粗参数 CSCV/PBO。

因此当前最诚实的判断是：

> 低噪增强不是“整个策略都是假信号”，但其最后一层存在可确认的调参风险；C3/L3 的新增信息有较强独立增量证据，但高收益版仍继承低噪底座的模型选择风险，不能称为“已经没问题”。

### 修复原则

`BacktestEngine.runRiskContributionCashConfidenceRouterWithTrace` 对 `.lowNoiseNoLeverage` 明确冻结：

- 决策层手续费：1.00%；
- 决策层滑点：0.05%；
- 用户输入费用：只进入最终执行层。

默认 1% 口径下 `APP_BASELINE_VERIFY_OK`，因此修复不重写历史 golden baseline。

## 4. 最大回撤压力测试

1,200 次 moving-block bootstrap：

### 低噪增强

- 20 日块：MDD 95% 区间约 `8.45% / 11.47% / 17.33%`（P2.5 / median / P97.5）
- 63 日块：`7.67% / 9.98% / 14.45%`
- 252 日块：`7.46% / 8.15% / 11.15%`

### C3/L3 高收益版

- 20 日块：约 `8.56% / 11.46% / 17.70%`
- 63 日块：`7.81% / 9.96% / 14.32%`
- 252 日块：`7.46% / 8.26% / 11.44%`

因此 **7.93% 是历史实现 MDD，不应解释成未来风险上限**。在保留部分时间相关性的路径重排中，约 10%~12% 的中位压力 MDD 更适合作为风险认知基线，尾部还可能更高。

## 5. 策略主链归因

同一数据、同一 1% + 0.05% 成本：

| 阶段 | CAGR | MDD | Sharpe |
|---|---:|---:|---:|
| 风险贡献再分配 | 10.69% | 9.49% | 1.167 |
| + 制度路由 | 11.64% | 9.49% | 1.184 |
| + 水下恢复 | 12.16% | 9.42% | 1.197 |
| + Cash Confidence | 11.15% | **7.24%** | **1.482** |
| + Low Noise | **14.45%** | 7.93% | **1.509** |

主要结论：

- 最大的风险调整收益跃升来自 Cash Confidence，而不是最后的低噪微调；
- Low Noise 最后一层主要负责重新提高风险利用率和 CAGR，Sharpe 仅从 1.482 提高到 1.509；
- 因此应优先审计 Low Noise 新增自由度，而不是把整个 1.509 都视作同一种过拟合风险。

## 7. NFCI C3/L3 模块审计

冻结规则：

- Credit initial-release 8 次发布变化 <= -0.03；
- Leverage initial-release 4 次发布变化 <= -0.03；
- 单触发仅保留一半原拟卖美股；双触发保留全部该次美股减仓；
- broad derisk 时 Generic100；
- 不新增日常交易日；不融资；gross <= 1；
- point-in-time initial-release 数据。

### 7.1 费用不变性

对 `Cash Confidence + C3/L3` 只加一个固定风险倍率并 cap 100%：

该曲线明显比 Low Noise 的精调参数平滑。若继续沿历史 `MDD <= 8%` 研究约束，1.3× 是自然风险边界，但尚不能因为这一点直接将其称为 OOS 最优。

- 3年滚动最差 Sharpe 0.448（Low Noise 0.576）；

- 252日块 MDD 中位约 8.11%，Low Noise 约 8.15%。

因此“低自由度/宽平台”是它的建模优势，但它在短中期滚动窗口并未全面优于 Low Noise。**简单不能替代真实时间稳定性验证**；1.3× 目前保留为稳健结构对照，不直接晋级生产。

## 9. 50/50 双核心结构参考

结构：

- 50% `Low Noise + C3/L3`；
- 50% `Cash Confidence + C3/L3 + static 1.3x`；
- 两个袖套独立计费，因此结果相对单账户净额成交偏保守。

结果：

- full：14.51% CAGR / 7.48% MDD / 1.535 Sharpe；
- 2020+：17.38% / 7.48% / 1.608；
- 2022+：20.58% / 6.41% / 1.754。

滚动 Sharpe 改善相对 Low Noise：

- 3年约57%；
- 5年约58%；
- 10年约86%。

但滚动 CAGR 在3/5年仅约39%/50%的窗口更高，因此**不能称为全面支配策略**。不继续搜索 60/40、70/30 等权重，避免新的权重拟合。

## 10. 当前策略分层建议

### A. 稳健研究核心

`Cash Confidence + C3/L3`

- 逻辑最简；
- 历史 MDD 7.24%；
- Sharpe 1.519；
- NFCI 增量跨底座成立。

### B. 平衡研究核心

`Cash Confidence + C3/L3 + static 1.3x risk budget`

- CAGR 13.69%；
- MDD 7.81%；
- Sharpe 1.504；
- 单一风险倍率 1.0~1.5 呈宽平台。

### C. 高收益研究版

`Low Noise + C3/L3`

- CAGR 15.21%；
- MDD 7.93%；
- Sharpe 1.546；
- NFCI 模块本身稳健；
- 但仍继承 Low Noise 的 trade-band / active-scale 参数拟合风险。

因此 **C 不应直接进入 App 生产策略**，除非进一步简化/集成低噪层，或积累冻结后的真正 prospective OOS。

## 11. 与资产无关泛化验证的关系

此前独立资产无关价格-only V2/V3/V4 三次正式跨市场 OOS 均未通过全部预注册门槛。V4 第三批 8 国：

- MDD 26.70%；
- 8/8 单市场 Sharpe > 0；
- ticker rename invariance PASS；

因此当前任何五资产低噪/NFCI结果都不能被描述为“已经证明跨任意市场泛化”。

## 12. 下一步硬门槛

在考虑 App 晋级前继续完成：

1. 把费用目标-path不变性加入长期回归测试；
2. 对低噪 trade-band 与 active-scale 设计更平滑、低自由度替代，而不是重新寻找另一个历史最优小数；
3. 对简化核心做滚动/分年代和事件级 ablation；
4. prospective trial registry：今后的候选在运行前登记参数族、目标指标与停止规则；
5. 从 2026-08-14 冻结日起持续积累真实前瞻 OOS；
6. 未来新市场/新资产只允许一次性冻结验证，不再 holdout shopping。

## 13. 当前判断

- **低噪增强：** 有真实长期优势，但最后一层有明确参数拟合风险；历史 1.509 Sharpe 可信度应打折，历史7.93% MDD更不能当风险上限。
- **NFCI C3/L3：** 目前审计结果明显更健康，新增因子本身具有统计与经济增量；但高收益版本仍依赖低噪底座，因此不能称为“没有问题”。
- **更值得产品化的方向：** 从 `Cash Confidence + C3/L3` 这个简单核心出发，再使用宽平台风险预算，而不是继续堆叠低噪微规则。

## 14. 审计后的冻结优化轮次 V1/V2/V3

本报告完成后，没有继续自由搜索参数，而是连续建立三份先写协议、后运行结果的 retrospective 验证。

### V1：固定6候选嵌套/时间折验证

6个候选全部过基础硬门槛；预注册 robust score 仍由 `LowNoise + C3/L3`（C0）最高。动态 walk-forward selector 只把 Sharpe从同期 LowNoise约1.480提高到1.487，却明显牺牲 CAGR，因此没有产品化价值。

### V2：结构平滑替代

尝试 trade-to-band-boundary 与统一 active scale。结果只有原 C0 通过所有门槛；所有平滑替代均正式记录 FAIL。Soft20/Soft25 的 Sharpe仅差约0.005，说明带宽尖峰得到缓解，但收益效率与跨时间折表现不足。因此没有为了得到“更简单赢家”而降低门槛。

### V3：目标仓位模型集成

预注册候选只包含 Bag9、50/50 DualCore、三核心等权；未搜索混合权重。

- Bag9 单账户目标平均：14.76% CAGR / 7.93% MDD / 1.508 Sharpe；20/25/30%执行带 Sharpe spread仅0.030，证明模型平均显著缓解带宽敏感性，但只有2/7折 Sharpe不差于 C0，FAIL。
- TripleCore：13.37% / 7.36% / 1.538；风险较低但 CAGR<14%预注册门槛，FAIL。
- **DualCore 50/50 target blend：14.58% / 7.69% / 1.535，唯一新候选 PASS。** 7个时间折中4折 Sharpe更高，7/7折 MDD更低，block63 MDD P97.5约14.09%（C0约14.58%）。

DualCore 的 C0/C2 两个底层模型在用户执行费1.00%与0.03%下生成的6395日目标CSV byte-for-byte identical；最终目标 fingerprint `9b20947b8640091b` 不随费用变化。

配对 block bootstrap 也显示 DualCore 是明确的风险分散取舍而非免费Alpha：CAGR中位约少0.59pp/年，约70%路径MDD更低，Sharpe中位仅低约0.011。

因此当前审计后 Pareto 结论是：

- **高收益研究主线：C0 LowNoise + C3/L3** — 15.21% / 7.93% / 1.546；
- **平衡/模型风险分散主线：DualCore** — 14.58% / 7.69% / 1.535；
- 现有生产 LowNoise 保持不变，等待前瞻 OOS。

DualCore 已单独登记 `prospective-oos-registry-2026-08-14-v2.md`，不得再在同一版本上调整50/50或25%执行带。
