# 低噪增强外部状态升级：NFCI Generic100 C3/L3 研究冠军

日期：2026-08-13
状态：**冻结研究冠军，尚未进入 App 生产策略**

## 1. 结论

当前找到的最稳健高质量候选是在生产 `risk-contribution-cash-confidence-low-noise` 之上增加一个**只在原策略准备减仓时生效的实时金融条件缓冲层**。

冻结候选：

- NFCI Credit 初始发布值，8 周变化 `<= -0.03`；
- NFCI Leverage 初始发布值，4 周变化 `<= -0.03`；
- 所有 NFCI 数据按 initial release / release date 使用，不读取之后修订值；
- 只在生产策略原本就发生的调仓日判断，不创造新的日常交易日；
- 当生产策略计划将美股目标一次减少至少 5 个百分点、同时总风险仓位下降至少 3 个百分点时：
  - Credit 或 Leverage 仅一个触发：只执行一半美股减仓，保留另一半；
  - 两者同时触发：本次保留全部原美股仓位，不执行该美股减仓；
- 如果金融条件触发，但本次主要是总组合广泛减仓且总风险仓位下降至少 5 个百分点，则本次保留原先拟卖出的风险仓位（Generic100）；
- 总风险资产仍严格不超过 100%；
- 不融资、不做空、不允许负现金；
- 执行成本保持 App 当前正式口径：单边 1.00%交易费 + 0.05%滑点；
- 信号严格使用 T-1 可知数据，T 日执行。

经济含义：NFCI Credit / Leverage 子指标持续下降代表对应金融条件正在放松。当生产价格状态机恰好准备大幅降风险、而实时信用/杠杆环境正在明显缓和时，候选并不反向加仓，只是降低或取消这次减仓强度，避免在改善中的金融条件下过早卖出。

## 3. 阈值平台验证

不是只搜索一个最漂亮的小数点。固定结构后检查：

- Credit 8周阈值：`-0.02 / -0.03 / -0.04`；
- Leverage 4周阈值：`-0.03 / -0.04 / -0.05`；
- Generic 缓冲：`75% / 90% / 100%`。

共 27 个粗粒度组合。

关键结果：

- `Credit=-0.03, Leverage=-0.03, Generic=100%`：15.208627% / DD 7.931053% / Sharpe 1.545038；
- 同阈值 Generic=90%：15.199212% / DD 7.931053% / Sharpe 1.544724；
- 同阈值 Generic=75%：15.165392% / DD 7.931053% / Sharpe 1.542003；
- `Credit=-0.04, Leverage=-0.03` 的 90%/100%版本：15.136326% / DD 7.931053% / Sharpe 1.541250；
- `Credit=-0.03, Leverage=-0.04, Generic=100%`：15.114166% / DD 7.931053% / Sharpe 1.540581；
- `Credit=-0.03, Leverage=-0.05, Generic=100%`：15.066168% / DD 7.931053% / Sharpe 1.539127。

因此 `Credit=-0.03~-0.04`、`Leverage=-0.03~-0.05`、Generic 75%–100% 形成明显宽平台，普遍优于当前生产。

相反，`Credit=-0.02` 的所有邻近组合最大回撤均突然扩大到约 11.47%，Sharpe 降至约 1.46–1.47。说明过宽 Credit 触发区是明确错误区，而不是最佳点附近缺乏稳定性。

选择 `-0.03/-0.03/100%` 是因为它使用简单整数百分比/百分位式粗阈值、处于稳定区域且当前综合指标最好，不继续搜索更细的 `-0.028/-0.032` 等小数。
