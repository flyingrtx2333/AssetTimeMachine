# 无融资置信度恢复：纯调仓执行研究

日期：2026-07-18

## 产品约束

- 现金只使用项目现有 `CashYieldCNY` 人民币活期存款模型；
- 不使用定期存款、货币基金、逆回购或任何现金收益增强；
- 默认成本保持 1.00% 手续费与 0.05% 滑点；
- 不融资，总仓位不超过 100%；
- 研究重点仅限资产目标生成后的调仓执行方式。

## 当前纯调仓冠军

- 恢复袖套快速破位阈值：双指数三日共同跌幅由 -3% 放宽到 -5%；

## 本轮调仓结构实验

### 1. 两阶段领导权交接

结构：新领导资产出现时先迁移 0% / 33% / 50%，等待 10 日相对表现验证后再完成迁移。

结果：全历史夏普约 1.487–1.497，均低于基线 1.5247。虽然部分方案改善 2020+ 与 2022+，但全历史失效，淘汰。

### 2. 逐资产权重无交易区

结构：每个资产 3% 以内变化不交易，或只交易到目标区间边界。

结果：交易次数可从 461 降到约 282–336，但全历史夏普降至约 1.387–1.500。小幅目标变化包含有效信息，淘汰。

### 3. 新增仓位持续确认

结构：减仓立即执行；新增仓位必须连续确认 2 / 3 / 5 日才买入。

结果：全历史夏普分别约 1.475 / 1.453 / 1.378。确认延迟明显损失有效早期收益，淘汰。

### 4. 仅按组合偏离触发调仓

结构：取消 `baseTargetChanged` 强制触发，只在组合 L1 偏离超过 5% / 10% / 15% / 20% 时调仓。

结果：最好方案约 1.515，仍低于基线；说明底层目标更新本身需要即时执行，淘汰。

### 5. 风险归一化无交易区

结构：按 `|目标权重变化| × 63日年化波动` 衡量风险偏离，而非使用统一权重阈值。

结果：全历史夏普约 1.501–1.518，未超过基线。低波动阶段局部有效，但其他阶段被拖累。

### 6. 低波动自适应风险死区

结构：仅当策略自身 60 日年化波动低于 4%–6% 时，启用风险归一化无交易区；高波动时期即时执行。

最好结果：

- 全历史年化：11.255328%；
- 最大回撤：7.237164%；
- 夏普：1.525132；
- 交易次数：458。

相对基线夏普仅提高约 0.00038，减少 3 笔交易，幅度不足以排除统计噪声，因此不采用。

## 当前执行结论

在现有资产池和目标生成器下，最佳执行原则仍然是：

1. 风险资产目标发生变化后立即执行，不等待额外确认；
2. 不使用统一或风险归一化的小额无交易区；
3. 不用固定日历批处理目标变化；
4. 不对新增仓位分批或延迟；
5. 仅恢复袖套采用明确的退出迟滞：-5% 快速破位和 150 日冷却；
6. 现金始终按人民币活期存款处理。

## 判断

纯执行层尚未找到可将全历史夏普从 1.5257 推升到 1.6 的结构。现有结果表明，继续围绕确认天数、阈值和无交易区细调，极易成为过拟合且收益空间很小。

下一步若继续坚持“只研究调仓”，应研究更高层的执行架构，例如：

- 将风险下降、资产横向迁移和总风险增加拆成不同的执行队列；
- 对大规模换仓使用风险贡献优先级和单次换手预算，而不是统一比例分批；
- 直接记录每次调仓后的 5/20/60 日增量收益与成本，建立在线执行质量学习器。

以上方向应先建立调仓事件归因数据，再设计规则，避免继续盲目网格搜索。
